### ✦ Overview

Transliterates Gujarati text to Latin characters, handling consonants, vowel signs and the halant.

### ✦ Usage

```typescript
import { romanizeGujarati } from "@romanizer/gujarati";

romanizeGujarati("ગુજરાતી");
```
