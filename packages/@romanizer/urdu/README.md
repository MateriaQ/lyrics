### ✦ Overview

Transliterates Urdu text to Latin characters with special handling for Islamic terms and common phrases.

### ✦ Usage

```typescript
import { romanizeUrdu } from "@romanizer/urdu";

romanizeUrdu("ہم"); // "hum"
romanizeUrdu("السلام علیکم"); // "Assalamu Alaikum"
```
