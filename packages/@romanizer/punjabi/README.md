### ✦ Overview

Transliterates Gurmukhi Punjabi text to Latin using the Hunterian scheme, handling nukta pairs, adhak, vowel signs and the halant.

### ✦ Usage

```typescript
import { romanizePunjabi } from "@romanizer/punjabi";

romanizePunjabi("ਪੰਜਾਬੀ");
```
