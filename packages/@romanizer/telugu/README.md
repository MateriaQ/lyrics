### ✦ Overview

Transliterates Telugu text to Latin characters, handling consonants, vowel signs and the virama.

### ✦ Usage

```typescript
import { romanizeTelugu } from "@romanizer/telugu";

romanizeTelugu("తెలుగు");
```
