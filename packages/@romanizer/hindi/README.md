### ✦ Overview

Transliterates Devanagari Hindi text to Latin characters, handling nukta pairs, consonants, vowel signs and the halant.

### ✦ Usage

```typescript
import { romanizeHindi } from "@romanizer/hindi";

romanizeHindi("हिन्दी");
```
