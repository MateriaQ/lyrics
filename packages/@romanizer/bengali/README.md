### ✦ Overview

Transliterates Bengali (Bangla) text to Latin characters, handling consonant clusters, vowel signs, hasanta and nukta.

### ✦ Usage

```typescript
import { romanizeBengali } from "@romanizer/bengali";

romanizeBengali("বাংলা");
```
