### ✦ Overview

Transliterates Georgian text to Latin characters using a fixed character map, passing non-Georgian characters through unchanged.

### ✦ Usage

```typescript
import { romanizeGeorgian } from "@romanizer/georgian";

romanizeGeorgian("საქართველო");
```
