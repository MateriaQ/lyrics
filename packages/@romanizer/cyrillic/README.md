### ✦ Overview

Transliterates Cyrillic script to Latin, powered by [`cyrillic-romanization`](https://www.npmjs.com/package/cyrillic-romanization).

### ✦ Usage

```typescript
import { romanizeCyrillic } from "@romanizer/cyrillic";

romanizeCyrillic("привет");
```
