### ✦ Overview

Transliterates Tamil text to Latin characters, handling consonants, vowel signs, the pulli and the க்ஷ ligature.

### ✦ Usage

```typescript
import { romanizeTamil } from "@romanizer/tamil";

romanizeTamil("தமிழ்");
```
