### ✦ Overview

Transliterates Malayalam text to Latin characters, handling chillu, consonants, vowel signs and the virama.

### ✦ Usage

```typescript
import { romanizeMalayalam } from "@romanizer/malayalam";

romanizeMalayalam("മലയാളം");
```
